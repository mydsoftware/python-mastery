# Python Mastery — 1155 تمرین واقعی Python

یک محیط تمرین تعاملی فارسی برای یادگیری Python از مبانی تا مباحث پیشرفته.

## ویژگی‌ها

- ۱۱۵۵ تمرین شماره‌گذاری‌شده
- دسته‌بندی موضوعی از مبانی تا پروژه‌های ترکیبی
- اجرای واقعی Python داخل مرورگر با Pyodide/WASM
- دکمه «جواب مسئله» برای نمایش پاسخ آماده
- تست‌های خودکار برای هر تمرین
- راهنمای مرحله‌ای
- حفظ کد نوشته‌شده و وضعیت تمرین در مرورگر
- بدون نیاز به نصب Python برای کاربر
- طراحی RTL و فارسی

## دیتاست تمرین‌ها

منبع اصلی تمرین‌ها در `data/exercises.json` قرار دارد و دقیقاً ۱۱۵۵ رکورد مستقل دارد. هر رکورد شامل `id`، `title`، `level`، `category`، `topic`، `statement`، `examples`، `starter_code`، `solution`، `tests`، `hints` و `concepts` است.

هر تمرین شامل عنوان، سطح، مبحث، صورت مسئله، مثال، محیط کدنویسی، اجرای واقعی، پاسخ آماده، حداقل سه تست و راهنمای مرحله‌ای است.

برای کنترل کیفیت، `scripts/validate-dataset.mjs` تعداد تمرین‌ها، یکتا بودن شناسه‌ها، فیلدهای ضروری، تعداد تست‌ها و تکرارهای مشکوک را بررسی می‌کند. این اعتبارسنجی در GitHub Actions نیز اجرا می‌شود.

## دسته‌بندی

مبانی Python، متغیرها و انواع داده، ورودی/خروجی، شرط‌ها، حلقه‌ها، رشته‌ها، List، Tuple، Set، Dictionary، Functions، Lambda، Scope، Modules، Exceptions، Files، OOP، Inheritance، Iterator / Generator، Decorator، Context Manager، Regex، JSON، Date/Time، الگوریتم‌ها، Recursion، Stack / Queue، Tree / Graph، Async، Type Hints، Dataclass / Enum، SQLite، Networking، Testing، Performance، Security و پروژه‌های ترکیبی.

## اجرای محلی

فایل‌ها یک وب‌اپ مستقل هستند و می‌توانند با هر static server اجرا شوند.

## تنظیم Pyodide برای ایران

در رابط کاربری، بخش «Mirror Pyodide» اضافه شده است. می‌توانید آدرس mirror یا سرور داخلی خودتان را وارد کنید؛ مسیر باید به پوشه `full/` مربوط به Pyodide نسخه `0.27.7` ختم شود. اگر mirror سفارشی تنظیم نشود، برنامه به صورت خودکار چند CDN پشتیبان را امتحان می‌کند.

## اعتبارسنجی نهایی

GitHub Actions روی هر push/PR دیتاست را بررسی می‌کند: تعداد دقیق ۱۱۵۵ تمرین، شناسه‌های متوالی، تعداد تمرین‌های هر دسته، فیلدهای ضروری، دقیقاً سه تست، حداقل سه راهنما و تکرارهای مشکوک.

## وضعیت نسخه نهایی
